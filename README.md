# The Saviours - Multiplayer Game

This is "The Saviours" a 3D multiplayer co-op game built in Unity using Photon networking. Each session supports up to eight players who join a shared room and explore a seamless world together. Players can freely roam the environment, interact with one another, and team up to fight various enemies. The game focuses on cooperative exploration, social interaction, and dynamic combat in a shared online world.
